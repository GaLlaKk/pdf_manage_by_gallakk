# GaLlaKk द्वारा PDF Manager

PDF पृष्ठों को जोड़ने, अलग करने, संपीड़ित करने, घुमाने और उनका क्रम बदलने के लिए Python डेस्कटॉप ऐप। यह ऐप स्थानीय रूप से चलता है, इसलिए आप निजी PDF को किसी ऑनलाइन सेवा पर अपलोड या साझा किए बिना प्रबंधित कर सकते हैं।

## सुविधाएँ

- कई PDF को एक दस्तावेज़ में जोड़ें।
- PDF को अलग-अलग पृष्ठों में बाँटें।
- PDF को लॉसलेस या संतुलित मोड में संपीड़ित करें।
- सहेजने से पहले पृष्ठों को घुमाएँ और उनका क्रम बदलें।
- लंबे समय तक चलने वाले कार्यों की प्रगति देखें।

## डाउनलोड

`v*` टैग के साथ जारी किए गए प्रत्येक संस्करण के लिए GitHub Actions Windows, Linux और macOS के स्वतंत्र पैकेज बनाता है। अपने सिस्टम के लिए पैकेज संबंधित [GitHub Releases](https://github.com/GaLlaKk/pdf_manage_by_gallakk/releases) पृष्ठ के **Assets** अनुभाग से डाउनलोड करें; Python इंस्टॉल करने की आवश्यकता नहीं है।

ऐप का संस्करण विंडो के शीर्षक में दिखाया जाता है। ऐप का आइकन Windows निष्पादन योग्य फ़ाइल और macOS ऐप बंडल में शामिल है; इसका उपयोग ऐप विंडो, लोडिंग संवाद और टास्कबार में भी होता है।

macOS पर, ऐप हस्ताक्षरित या नोटराइज़ नहीं है, इसलिए पहली बार चलाने पर **सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा** में अनुमति देनी पड़ सकती है। Linux पैकेज उनके नाम में बताई गई आर्किटेक्चर के लिए हैं और इनके लिए Tk समर्थन वाला ग्राफ़िकल डेस्कटॉप आवश्यक है।

## संस्करण और रिलीज़

`pdf_manager_version.py` ऐप में दिखाए जाने वाले संस्करण का एकमात्र स्रोत है। रिलीज़ के लिए इस फ़ाइल में `__version__` अपडेट करें, फिर `v` उपसर्ग वाला संबंधित Git टैग बनाकर पुश करें। संस्करण `1.0.0` का उदाहरण:

```bash
git tag v1.0.0
git push origin v1.0.0
```

इसी workflow को रिपॉज़िटरी के **Actions** टैब से मैन्युअल रूप से भी शुरू किया जा सकता है; ऐसे बिल्ड workflow artifacts के रूप में उपलब्ध होते हैं।

## सोर्स कोड से चलाएँ

Python 3.10 या नया संस्करण और ऐप की निर्भरताएँ इंस्टॉल करें, फिर ऐप चलाएँ:

```bash
python -m pip install -r requirements.txt
python pdf_manager.py
```

टेस्ट चलाने के लिए:

```bash
python -m pip install -r requirements-build.txt
python -m pytest -q
```

## प्रोजेक्ट संरचना

- `pdf_manager.py`: ऐप का प्रवेश बिंदु और मुख्य विंडो का संचालन।
- `pdf_manager_ui/`: मर्ज, विभाजन, संपीड़न और पूर्वावलोकन सुविधाओं के अनुसार व्यवस्थित UI।
- `assets/icons/`: ऐप आइकन की स्रोत फ़ाइलें।
- `scripts/`: बिल्ड और रिलीज़ पैकेजिंग के स्वतंत्र स्क्रिप्ट।
- `tests/`: ऐप और PDF सेवा के परीक्षण।
- `pdf_manager_version.py`: ऐप में दिखाया जाने वाला संस्करण।
