# PDF Manager من GaLlaKk

تطبيق سطح مكتب مكتوب بلغة Python لدمج ملفات PDF وتقسيمها وضغطها وتدوير صفحاتها وإعادة ترتيبها. يعمل التطبيق محليًا، لذا يمكنك إدارة ملفات PDF دون رفع مستنداتك الخاصة أو مشاركتها مع خدمة عبر الإنترنت.

## الميزات

- دمج عدة ملفات PDF في مستند واحد.
- تقسيم ملف PDF إلى صفحات منفردة.
- ضغط ملفات PDF في الوضع غير الفاقد أو المتوازن.
- تدوير الصفحات وإعادة ترتيبها قبل الحفظ.
- عرض تقدم العمليات التي تستغرق وقتًا.

## التنزيلات

لكل إصدار منشور بعلامة `v*`، تنشئ GitHub Actions حزمًا مستقلة لأنظمة Windows وLinux وmacOS. نزّل الحزمة المناسبة لنظامك من قسم **Assets** في صفحة الإصدار المقابلة على [GitHub Releases](https://github.com/GaLlaKk/pdf_manage_by_gallakk/releases)؛ لا حاجة إلى تثبيت Python.

يظهر إصدار التطبيق في عنوان النافذة. يتضمن الملف التنفيذي لنظام Windows وحزمة تطبيق macOS أيقونة التطبيق، وتُستخدم أيضًا في نافذة التطبيق ومربع حوار التحميل وشريط المهام.

في macOS، قد يتطلب التشغيل الأول السماح بالتطبيق من **إعدادات النظام ← الخصوصية والأمان**، لأن التطبيق غير موقّع وغير موثّق لدى Apple. تستهدف حزم Linux البنية المذكورة في اسم الحزمة، وتتطلب بيئة سطح مكتب رسومية تدعم Tk.

## الإصدارات والنشر

يُعدّ `pdf_manager_version.py` المصدر الوحيد لإصدار التطبيق المعروض. لنشر إصدار، حدّث `__version__` في هذا الملف، ثم أنشئ وادفع علامة Git المطابقة التي تبدأ بـ `v`. مثال للإصدار `1.0.0`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

يمكن أيضًا بدء سير العمل نفسه يدويًا من علامة التبويب **Actions** في المستودع؛ وتكون الحزم الناتجة متاحة كعناصر بناء لسير العمل.

## التشغيل من المصدر

ثبّت Python 3.10 أو إصدارًا أحدث وتبعيات التطبيق، ثم شغّل التطبيق:

```bash
python -m pip install -r requirements.txt
python pdf_manager.py
```

لتشغيل الاختبارات:

```bash
python -m pip install -r requirements-build.txt
python -m pytest -q
```

## بنية المشروع

- `pdf_manager.py`: نقطة دخول التطبيق وتنسيق النافذة الرئيسية.
- `pdf_manager_ui/`: وظائف الواجهة مجمّعة حسب الدمج والتقسيم والضغط والمعاينة.
- `assets/icons/`: الملفات المصدرية لأيقونات التطبيق.
- `scripts/`: نصوص مستقلة للبناء وتجهيز حزم الإصدارات.
- `tests/`: اختبارات التطبيق وخدمة PDF.
- `pdf_manager_version.py`: إصدار التطبيق المعروض.
