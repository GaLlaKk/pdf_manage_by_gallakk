# PDF Manager от GaLlaKk

Настольное приложение на Python для объединения, разделения, сжатия, поворота и изменения порядка страниц PDF. Приложение работает локально: управлять PDF можно без загрузки и передачи личных документов онлайн-сервису.

## Возможности

- Объединение нескольких PDF в один документ.
- Разделение PDF на отдельные страницы.
- Сжатие PDF без потерь или в сбалансированном режиме.
- Поворот и изменение порядка страниц перед сохранением.
- Отображение хода длительных операций.

## Загрузки

Для каждой версии с тегом `v*` GitHub Actions собирает автономные пакеты для Windows, Linux и macOS. Скачайте пакет для своей системы в разделе **Assets** на странице соответствующего выпуска [GitHub Releases](https://github.com/GaLlaKk/pdf_manage_by_gallakk/releases); устанавливать Python не требуется.

Версия приложения отображается в заголовке окна. Значок приложения включён в исполняемый файл Windows и пакет приложения macOS; он также используется в окне приложения, диалоге загрузки и на панели задач.

При первом запуске на macOS может потребоваться разрешение в разделе **Системные настройки → Конфиденциальность и безопасность**, поскольку приложение не подписано и не нотариально заверено. Пакеты Linux предназначены для архитектуры, указанной в имени пакета, и требуют графической среды рабочего стола с поддержкой Tk.

## Версии и выпуски

`pdf_manager_version.py` — единственный источник версии, отображаемой в приложении. Для выпуска обновите `__version__` в этом файле, затем создайте и отправьте соответствующий Git-тег с префиксом `v`. Например, для версии `1.0.0`:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Тот же workflow можно запустить вручную на вкладке **Actions** репозитория; собранные пакеты будут доступны как артефакты workflow.

## Запуск из исходного кода

Установите Python 3.10 или новее и зависимости приложения, затем запустите приложение:

```bash
python -m pip install -r requirements.txt
python pdf_manager.py
```

Чтобы запустить тесты:

```bash
python -m pip install -r requirements-build.txt
python -m pytest -q
```

## Структура проекта

- `pdf_manager.py`: точка входа приложения и управление главным окном.
- `pdf_manager_ui/`: интерфейс, сгруппированный по функциям объединения, разделения, сжатия и предварительного просмотра.
- `assets/icons/`: исходные файлы значков приложения.
- `scripts/`: отдельные скрипты сборки и упаковки выпусков.
- `tests/`: тесты приложения и PDF-сервиса.
- `pdf_manager_version.py`: версия, отображаемая в приложении.
